Identity chip for candidates, recruiters, admins and company logos.

```jsx
<Avatar name="Nguyễn Minh Anh" size="sm" />
<Avatar name="FPT Software" role="employer" size="md" />
```

Vietnamese names are given surname-first, so initials are built from surname + given name. Company avatars use the squared radius; a missing logo shows initials on Pine-100 — never a generic silhouette.
