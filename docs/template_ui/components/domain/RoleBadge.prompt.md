Labels which actor a session, message author or account belongs to: Candidate (Pine), Employer (Indigo), Admin (Plum).

```jsx
<RoleBadge role="employer" />
<RoleBadge role="admin" variant="solid" />
```

Use it in admin tables, message threads and account switchers. Inside a role's own app shell the `SideNav` rail already carries the colour — don't repeat the badge on every screen.
